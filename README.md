Checklist para que mi compa no se le pasen las **diarias** de sus gachas ni la **semanal del CS2** de los martes.
Hecho a la medida, con memes incluidos. 🫦🔥

## ✨ Qué hace

| | |
|---|---|
| ✅ **Diarias** | Genshit, Sueñering, Porn Dust, Honkai, ZZZ, UmaGodsume, MariaN (Nikke) — se desmarcan solas a medianoche |
| 📅 **Semanal** | Counter Strike 2 — se reinicia cada martes |
| 📊 **Progreso** | Barra y contador por sección, y cuenta regresiva al siguiente reinicio |
| 🖼️ **Meme del día** | Uno al azar cada día (motivación… o desilusión) |
| ❄️ **Nieve gacha** | Imágenes cayendo de fondo con `<canvas>` |
| 💾 **Sin cuentas** | Todo se guarda en el navegador con `localStorage` |

## 🛠️ Cómo funciona

```
index.html        estructura y lista de juegos
css/style.css     diseño (paleta Noguchi, vidrio, progreso)
js/script.js      guardado, reinicios diario/semanal, meme y nieve
memes/            memes del día
img/              favicon y la imagen que cae
```

- **Agregar un juego:** copia un `<li>` en `index.html` con un `id` nuevo (clase `daily-task` o `weekly-task`).
- **Agregar un meme:** súbelo a `memes/` y añade el nombre a `listaDeMemes` en `js/script.js`.
